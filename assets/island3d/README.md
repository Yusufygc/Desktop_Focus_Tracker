# 3D ada kaynak modelleri

Bu `.glb` dosyaları `tools/build_island_assets.py` tarafından prosedürel olarak üretilir (harici kaynak / lisans yok). Uygulama, `balsam` ile dönüştürülmüş `app/ui/qml/components/island3d/meshes/*.mesh` dosyalarını kullanır.

Subset (malzeme) sırası:

- `island_base`: grass, dirt, rock
- `pine_tree`: bark, leaf
- `oak_tree`: bark, leaf
- `stump`: bark, wood, leaf
- `hut`: log, roof, stone, wood
- `house`: stone, plaster, roof, wood, glass
- `farm`: barn, roof, wood, stone, plaster, trim, hay
- `windmill_blades`: wood, sail
- `village`: stone, plaster, roof, roof2, wood, glass, water
- `town`: stone, plaster, roof, roof2, wood, glass, gold
- `castle`: stone, stone_dark, roof, wood, gold, banner
- `lighthouse`: rock, white, red, glass, dark
- `monument`: stone, marble, gold
